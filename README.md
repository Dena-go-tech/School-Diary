# Дневник

Расписание по датам и домашние задания. Рассчитан в первую очередь на телефон.
Фронтенд — React + Vite, бэкенд — Node.js (Express) + PostgreSQL.

## Запуск в Docker

    cp .env.example .env   # при необходимости поменяйте пароль
    docker compose up -d --build

Откройте http://localhost (или http://<IP-компьютера> с телефона в той же Wi‑Fi сети).
Миграции базы применяются автоматически при каждом старте.

Создайте первого администратора (без него войти будет некому):

    docker compose exec app npm run createsuperuser

Входить ученикам не обязательно — без входа сайт работает в гостевом режиме.
Аккаунты учеников (если нужны) администратор добавляет в приложении: профиль → «Пользователи».
Из консоли тоже можно: `docker compose exec app npm run create-user -- --role student`.

## Разработка

    docker compose up -d db   # нужна база; порт 5432 должен быть доступен с хоста
    npm install
    npm run dev               # http://localhost:5173, API работает внутри Vite

Строка подключения берётся из `DATABASE_URL` (по умолчанию `postgres://diary:diary@localhost:5432/diary`).

## Роли
- **Гость** — любой посетитель без входа. Права как у ученика: смотрит расписание и ДЗ, отмечает
  «выполнено», предлагает ДЗ (с именем). Гостевой профиль создаётся при первом действии и живёт в cookie
  устройства. Ограничения от спама: до 10 запросов на проверке у гостя, до 200 у всех гостей вместе,
  до 10 новых гостей с одного IP в час.
- **Ученик** (аккаунт от администратора) — то же самое, но под своим логином на любом устройстве.
- **Администратор** — меняет расписание и предметы, задаёт ДЗ, принимает или отклоняет запросы
  (принятый запрос дописывается к уже заданному ДЗ, если оно есть), управляет пользователями.

## Миграции
Файлы `server/migrations/NNN_название.sql` применяются по порядку, каждый в своей транзакции;
применённые записываются в таблицу `schema_migrations`. Новая миграция — новый файл со следующим номером.
Вручную: `npm run migrate`.

## Структура
- `server/db.js` — подключение к Postgres, запуск миграций
- `server/auth.js` — пароли (scrypt), сессии в cookie, роли, пользователи
- `server/app.js` — REST API (`/api/state`, `/api/subjects`, `/api/versions`, `/api/homework`, `/api/auth`, `/api/users`)
- `server/scripts/` — `create-user.js` (суперюзер), `migrate.js`
- `server/index.js` — production-сервер (API + собранный фронтенд)
- `src/lib/diary.js` — правила: версии расписания, перенос ДЗ
- `src/lib/useDiary.js` — загрузка данных и действия (с мгновенным обновлением UI)
- `src/components/` — экраны и диалоги

## Правила
- ДЗ, заданное на уроке, автоматически попадает на следующий урок того же предмета (в другой день).
- Расписание хранится версиями по датам: прошлые дни не меняются.
- Изменение расписания до 08:00 действует с сегодняшнего дня, после 08:00 — со следующего.
